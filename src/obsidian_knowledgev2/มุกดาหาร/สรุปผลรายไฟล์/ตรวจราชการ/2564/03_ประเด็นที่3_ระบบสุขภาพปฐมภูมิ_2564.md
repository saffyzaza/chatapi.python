# ประเด็นที่ 3 ระบบสุขภาพปฐมภูมิ — มุกดาหาร ปี 2564 (รอบ 2)

## ภาพรวม
ประเด็นการตรวจราชการ Agenda Based ประเด็นที่ 3 ระบบสุขภาพปฐมภูมิ จังหวัดมุกดาหาร ปีงบประมาณ 2564 รอบที่ 2

---

## 3.1 ประชาชนคนไทยมีหมอประจำตัว 3 คน
- จำนวนครอบครัวที่มีหมอประจำตัว 3 คน จำแนกรายอำเภอ
- การจัดระบบบริการสุขภาพ เชื่อมโยงจากทุติยภูมิสู่ปฐมภูมิและชุมชน (อสม.)
- จำนวนผู้ป่วยติดบ้าน ติดเตียง จำแนกรายอำเภอ
- จำนวนร้อยละ อสม. หมอประจำบ้าน แยกรายอำเภอ

## 3.2 การจัดตั้งหน่วยบริการปฐมภูมิและเครือข่ายหน่วยบริการสุขภาพ
- ตามพระราชบัญญัติระบบสุขภาพปฐมภูมิ พ.ศ. 2562
- ร้อยละของการจัดตั้งหน่วยบริการปฐมภูมิและเครือข่ายหน่วยบริการสุขภาพปฐมภูมิ จำแนกรายอำเภอ
- จำนวนงบประมาณ/โครงการในการขับเคลื่อนการดำเนินงานระบบสุขภาพปฐมภูมิ

## 3.3 อำเภอผ่านเกณฑ์การประเมินการพัฒนาคุณภาพชีวิตที่มีคุณภาพ
- คะแนนประเมิน UCCARE แยกเป็นรายอำเภอ
- จำนวนและร้อยละของอำเภอผ่านเกณฑ์การพัฒนาคุณภาพชีวิตระดับอำเภอที่มีคุณภาพ
