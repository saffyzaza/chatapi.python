# รายงานความก้าวหน้าโครงการ NCDs Remission Clinic จังหวัดอำนาจเจริญ (2568)

## 1. ผลการดำเนินงานเชิงโครงสร้าง
- **ความครอบคลุมคลินิก:**
  - รพท. / รพช. จัดตั้ง NCDs Remission Clinic ครบ **100%** (7 แห่ง)
  - รพ.สต. (NPCU) จัดตั้งครบ **100%** (32 แห่ง)
  - ศูนย์เรียนรู้ไทยห่างไกล NCDs จัดตั้งครบทุกตำบล (56 แห่ง)
  - สสอ. จัดตั้ง NCD Prevention Center ครบ **100%** (7 แห่ง)

## 2. ผลลัพธ์ทางคลินิก (Clinical Outcomes)
- **อัตราการเข้าสู่สภาวะสงบ (Remission Rate):**
  - ในกลุ่มผู้ป่วยที่สมัครใจเข้าคลินิก: **37.07%** (เป้าหมาย >= 10%) **ผ่านเกณฑ์ระดับสูง**
  - ในภาพรวมผู้ป่วย DM ทั้งหมดในพื้นที่: **1.48%** (เป้าหมาย >= 1%) **ผ่านเกณฑ์**
- **ความสำเร็จรายอำเภอ (Top 3 DM Remission):**
  - 1. อ.เสนางคนิคม (67.74%)
  - 2. อ.เมืองอำนาจเจริญ (65.88%)
  - 3. อ.ปทุมราชวงศา (61.21%)

## 3. ผลประโยชน์ทางเศรษฐศาสตร์ (Economic Impact)
- จำนวนผู้ป่วย DM ที่หยุดยาได้สำเร็จ: **123 ราย**
- **ประหยัดค่าใช้จ่าย:** ลดค่ารักษายาเบาหวานได้ **16,310 บาท/คน/ปี**
- **มูลค่าการประหยัดรวม:** **6,148,870 บาท**

## 4. ต้นแบบ "[[เสนางโมเดล]]" (Senang Model)
- **วิธีการ:** พัฒนาโรงเรียนเบาหวาน (Diabetes School) โดยทีมสหวิชาชีพ
- **ผลงาน (ก.ย. 67):** ผู้ป่วยเข้าโรงเรียน 37 ราย -> เข้าสู่ระยะสงบได้ 7 ราย (18.92%) -> ปรับลดขนาดยาได้ 21 ราย (56.76%)

## 5. ยุทธศาสตร์ "NCD New Care By 3 หมอ"
1. **หมอคนแรก (อสม. สู้เบาหวาน):** สำรวจผู้ป่วยรายครัวเรือน, คืนข้อมูลค่าน้ำตาล, แนะนำการลดคาร์บ
2. **หมอคนที่สอง (พยาบาล/เจ้าหน้าที่):** คัดกรองแยกกลุ่มสี, วางแผนติดตาม, ให้คำปรึกษาเชิงลึก
3. **หมอคนที่สาม (แพทย์):** วินิจฉัย, ปรับลดยา/หยุดยา, ติดตามสภาวะ Remission

## 6. แนวทางการขับเคลื่อนและข้อเสนอแนะ
- **นวัตกรรม:** 
  - ระบบ **[[VEMR]]** เชื่อมโยงข้อมูล 24x7
  - การใช้ **Intensive Lifestyle Modification** เป็นเครื่องมือหลัก
- **ปัญหา/อุปสรรค:** 
  - ต้องการระบบฐานข้อมูลกลางเพื่อค้นหากลุ่มเป้าหมายที่แม่นยำ
  - ขาดวัสดุอุปกรณ์ประจำศูนย์ป้องกัน NCDs ในบางตำบล
  - ต้องพัฒนาศักยภาพบุคลากรเฉพาะทางอย่างต่อเนื่อง
- **ก้าวต่อไป:** ขยายผล Best Practice จากเสนางโมเดลสู่ทุกอำเภอ และบูรณาการร่วมกับ "โครงการ อสม. สู้เบาหวาน"
