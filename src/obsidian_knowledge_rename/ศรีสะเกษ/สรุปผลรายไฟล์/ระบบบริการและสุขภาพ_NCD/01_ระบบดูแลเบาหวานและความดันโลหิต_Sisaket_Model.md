# ULTRA_DETAILED_NCD_DM_HT_Sisaket

## สถานการณ์โรคไม่ติดต่อเรื้อรัง (2568)
สำนักงานสาธารณสุขจังหวัดศรีสะเกษ (สสจ.ศรีสะเกษ) มุ่งเน้นการจัดการโรคไม่ติดต่อเรื้อรัง (NCDs) ตามเป้าหมาย Global NCDs Targets โดยเฉพาะ [[โรคเบาหวาน]] (DM), [[โรคความดันโลหิตสูง]] (HT), และโรคอ้วน

### ตัวชี้วัดและสถานการณ์ (ข้อมูลปี 2567-2568)
- **ประชากรเป้าหมาย (35 ปีขึ้นไป):** 1,428,328 คน (ข้อมูล HDC ณ 3 ต.ค. 68)
- **อัตราป่วยรายใหม่ (New Cases):**
	- **โรคเบาหวาน:** 7,972 ราย (558.14 ต่อแสนประชากร) สูงสุดในเดือน ต.ค. 67
	- **โรคความดันโลหิตสูง:** 20,884 ราย (1,462.13 ต่อแสนประชากร) สูงสุดในเดือน ต.ค. 67
- **การคัดกรองประชากร (35 ปีขึ้นไป):**
	- **เบาหวาน:** เป้าหมาย 500,542 คน | ผลงาน **306,190 คน (61.17%)** -> *ไม่ผ่านเกณฑ์ร้อยละ 90*
	- **ความดันโลหิตสูง:** เป้าหมาย 440,339 คน | ผลงาน **271,337 คน (61.62%)** -> *ไม่ผ่านเกณฑ์ร้อยละ 90*
- **การควบคุมโรค:**
	- ผปู้ป่วยเบาหวานควบคุมน้ำตาลได้ดี (HbA1c < 7%): **38.83%** (เป้าหมาย >= 40%)
	- ผู้ป่วยความดันโลหิตสูงควบคุมได้ดี (< 140/90): **58.35%** (เป้าหมาย >= 60%)
	- ผู้ป่วยเบาหวานที่ได้รับการตรวจ HbA1c อย่างน้อยปีละครั้ง: **81.20%** (เป้าหมาย >= 70%) -> *ผ่านเกณฑ์*

### โรคไตเรื้อรัง (CKD)
- ผู้ป่วยเบาหวานได้รับการตรวจภาวะแทรกซ้อนทางไต: **36,199 ราย (48.53%)**
- ผู้ป่วยโรคเบาหวานและควาันดันฯ ที่ได้รับการวินิจฉัยเป็นโรคไตเรื้อรังรายใหม่: **14,190 ราย (15.27%)**
- จำนวนผู้ป่วยไตเรื้อรัง Stage 5 รายใหม่: **49 ราย**
