# ประเด็นที่ 3-4: ระบบปฐมภูมิและสุขภาพกลุ่มวัย จ.อำนาจเจริญ รอบ 2/2564

## 1. ระบบสุขภาพปฐมภูมิ (Primary Care)
- **หมอประจำตัว 3 คน:** ดูแลประชากร 203,559 คน (51.04%)
- **PCU/NPCU:** จัดตั้งแล้ว 21 หน่วย (คิดเป็น 51.21% ของเป้าหมายใหม่ 41 หน่วย)
- **30 บาท รักษาทุกที่:** ยกเลิกใบส่งตัวภายในจังหวัด มีหน่วยบริการปฐมภูมิ 84 แห่งพร้อมรองรับ

## 2. สุขภาพกลุ่มวัยและสุขภาพจิต
- **แม่และเด็ก:** อัตราตายมารดา = 0 (ไม่มีรายงานเสียชีวิต), เด็ก 0-5 ปี พัฒนาการสมวัย 91.29%
- **ผู้สูงอายุ:** คัดกรองภาวะหกล้ม (TUGT) 27,042 คน พบเสี่ยง 3.95% และดูแลตาม Care Plan 1,305 ราย (81.56%)
- **สุขภาพจิต:** อัตราฆ่าตัวตายสำเร็จ 5.44 ต่อแสนประชากร (เป้าหมาย < 8) ติดตามกลุ่มเสี่ยง 64 รายไม่พบการทำร้ายตนเองซ้ำ
