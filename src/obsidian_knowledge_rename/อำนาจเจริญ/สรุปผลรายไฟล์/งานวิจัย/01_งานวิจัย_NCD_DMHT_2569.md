# สรุปผลการตรวจราชการและนิเทศงาน NCD (DM/HT) รอบที่ 1/2569 จ.อำนาจเจริญ

## 1. สถานการณ์และตัวชี้วัดสำคัญ (Q1/2569)
- **สถานการณ์รุนแรง:** ผู้ป่วยเบาหวานไม่สามารถควบคุมน้ำตาลได้ถึง **16,556 ราย (ร้อยละ 63.96)**
- **ภาระค่ารักษา:** ประมาณการค่ารักษาพยาบาลโรค NCDs สูงถึง **682.5 ล้านบาทต่อปี**
- **อัตราการเสียชีวิต:** พบการเสียชีวิตจากโรค NCDs เฉลี่ย **2 รายต่อวัน**
- **การเข้าถึงบริการ:** มีผู้ป่วยที่ต้องฟอกไตสะสม 965 ราย และยังมีผู้ป่วยที่ยังไม่ได้รับการค้นพบอีกประมาณ 12,117 ราย
รายงานสถานะผู้ป่วยโรคเบาหวาน (DM) และความดันโลหิตสูง (HT) เปรียบเทียบผลงานกับเป้าหมาย:

| ตัวชี้วัด (KPI) | เป้าหมาย | ผลงาน (Q1) | เขต 10 | ประเทศ |
| :--- | :---: | :---: | :---: | :---: |
| ยืนยันวินิจฉัยกลุ่มสงสัย DM | >= 70% | **32.72%** | 40.70% | 45.28% |
| ยืนยันวินิจฉัยกลุ่มสงสัย HT | >= 80% | **40.94%** | 56.46% | 61.10% |
| การควบคุมน้ำตาล (HbA1C < 7%) | >= 40% | **25.67%** | 25.83% | 25.56% |
| การควบคุมความดัน (< 140/90) | >= 60% | **55.35%** | 48.27% | 49.21% |
| [[DM Remission]] (ในคลินิก) | >= 10% | **On Process** | - | - |
| รายใหม่จากกลุ่ม Pre-DM | <= 1.75% | **1.14%** | 1.78% | 1.36% |

## 2. การวิเคราะห์รายพื้นที่ (District Performance)
- **อ.ปทุมราชวงศา:** มีผลการวินิจฉัยยืนยันสูงสุดทั้ง DM (53.61%) และ HT (49.42%)
- **อ.พนา:** มีการคัดกรองประชากร 35 ปีขึ้นไปได้ดีเยี่ยม (90.79%)
- **อ.เสนางคนิคม:** โดดเด่นด้านการควบคุมโรค (DM Control 53.76%)

## 3. มาตรการขับเคลื่อนเชิงรุก (PP&P Excellence)
1. **[[Active Case Finding]]:** ค้นหากลุ่มเสี่ยงในชุมชนด้วยระบบ Digital Health
2. **[[Mini-Case Manager]]:** พัฒนาศักยภาพบุคลากรในการบริหารจัดการรายกรณี
3. **[[VEMR]] & [[HIE]]:** เชื่อมโยงข้อมูลสุขภาพไร้รอยต่อระหว่างหน่วยบริการ
4. **[[DM Remission Service]]:** ใช้วิธี **Intensive Lifestyle Modification** (การปรับเปลี่ยนพฤติกรรมอย่างเข้มข้น)
5. **[[อสม. สู้เบาหวาน]]:** คืนข้อมูลค่าน้ำตาลและลดคาร์โบไฮเดรตในระดับครัวเรือน

## 4. ปัญหาและแนวทางแก้ไข (Gaps & Actions)
- **Gaps:** อัตราการวินิจฉัยยืนยัน (Confirmation) ยังต่ำกว่าเป้าหมายมาก; การบันทึกข้อมูลในระบบ 43 แฟ้มยังไม่ครบถ้วน
- **Actions:** 
  - เร่งรัดการนัดหมายกลุ่มสงสัยมาตรวจยืนยันภายใน 1-90 วัน (HT) และ 1-180 วัน (DM)
  - พัฒนาทีมวิทยากร/โค้ชระดับจังหวัดเพื่อสนับสนุนการจัดตั้ง **[[NCDs Remission Clinic]]** ให้ครบทุกตำบล
  - ติดตามผลลัพธ์ผ่าน **NCD Board** ทุกสัปดาห์
