# ประเด็นที่ 5: การพัฒนาระบบบริการสุขภาพ (Service Plan) รอบ 2/2568

**ช่วงการประเมิน:** รอบที่ 2 ประจำปีงบประมาณ 2568
**เป้าหมายหลัก:** ลดอัตราตายในโรควิกฤตฉุกเฉินและโรคสำคัญที่มีภาระค่าใช้จ่ายสูง

## ผลการดำเนินงานตามตัวชี้วัด (KPIs)

### 1. โรคหลอดเลือดสมอง (Stroke)
- **อัตราตาย:** **7.58%** 🔴 **สูงกว่าเกณฑ์เล็กน้อย** (เป้าหมาย < 7%)
- **การเข้าถึงบริการ:** รักษาใน Stroke Unit ภายใน 72 ชม. ได้ **89.30%** และเข้าถึงระบบ Stroke Fast Track ภายใน 4.5 ชม. ได้ **35.65%**

### 2. โรคกล้ามเนื้อหัวใจขาดเลือด (STEMI)
- **อัตราตาย:** **10.85%** 🔴 **ยังไม่ผ่านเกณฑ์** (เป้าหมาย < 9%)
- **กระบวนการรักษา:** 
  - ได้รับยาละลายลิ่มเลือด (Fibrinolytic) ใน 30 นาที: **82.76%**
  - ได้รับการสวนหัวใจ (Primary PCI): **62.75%**

### 3. โรคไตเรื้อรัง (CKD Stage 5)
- **ตัวชี้วัด:** ลดอัตราผู้ป่วยไตวายรายใหม่
- **ผลงาน:** ผู้ป่วยรายใหม่ลดลง **15.60%** 🟢 **ผ่านเกณฑ์** (เป้าหมายต้องลดลง > 10%) สะท้อนความสำเร็จจากคลินิกชะลอไตเสื่อมระดับปฐมภูมิ

### 4. มะเร็งครบวงจร (Cancer Warrior)
- **มะเร็งปากมดลูก:** คัดกรองด้วย HPV DNA Test สำเร็จ **25%** 🔴 **ต้องเร่งรัด**
- **มะเร็งลำไส้ใหญ่:** คัดกรองด้วย FIT Test สำเร็จ **111.65%** 🟢 **ทะลุเป้าหมาย**
