# ประเด็นที่ 5: ลดป่วย ลดตาย และสร้างความมั่นคงทางสุขภาพ รอบ 2/2566

**ช่วงการประเมิน:** รอบที่ 2 ประจำปีงบประมาณ 2566
**เป้าหมายหลัก:** การลดอัตราการตายในโรควิกฤตฉุกเฉินที่มีอัตราเสียชีวิตสูง

## ผลการดำเนินงานตามตัวชี้วัด (KPIs)

### 1. โรคกล้ามเนื้อหัวใจขาดเลือด (STEMI)
- **อัตราตาย:** **9.95%** 🔴 **สูงกว่าเกณฑ์เล็กน้อย (เป้าหมาย < 9%)**
- **กระบวนการรักษา:** ผู้ป่วยได้รับยาละลายลิ่มเลือด (Fibrinolytic) ภายใน 30 นาที ได้ถึง **93.26%** ซึ่งถือเป็นประสิทธิภาพที่ดีมากในระดับต้นทาง

### 2. โรคหลอดเลือดสมอง (Stroke)
- **อัตราตาย:** **7.95%** 🔴 **สูงกว่าเกณฑ์เล็กน้อย (เป้าหมาย < 7%)**
- **กระบวนการรักษา:** อัตราการเข้าถึง Stroke Fast Track ภายใน 4.5 ชั่วโมง ทำได้ **35.65%** ซึ่งยังคงเป็นความท้าทายของระบบส่งต่อในพื้นที่ห่างไกล

### 3. การคัดกรองมะเร็ง
- **มะเร็งปากมดลูก:** คัดกรองด้วยวิธี HPV DNA Test สำเร็จ **28.22%** 🔴 **ต้องเร่งรณรงค์เพิ่มเติม**
- **มะเร็งลำไส้ใหญ่:** คัดกรองด้วย FIT Test ในกลุ่มเสี่ยงสำเร็จ **43.33%**
