# ประเด็นที่ 3: บุคลากรเป็นเลิศ (People Excellence) รอบ 1/2569

**ช่วงการประเมิน:** ตุลาคม 2568 - มกราคม 2569
**เป้าหมายหลัก:** การบริหารจัดการกำลังคนให้เพียงพอ กระจายตัวเป็นธรรม และมีสมรรถนะสูง

## ผลการดำเนินงานตามตัวชี้วัด (KPIs)

### 1. การกระจายแพทย์ในระบบปฐมภูมิและโรงพยาบาลชุมชน
- **ตัวชี้วัด:** ร้อยละของเขตสุขภาพที่มีการบริหารจัดการกำลังคน (กระจายแพทย์ รพช.) ได้ตามเป้าหมาย (เป้าหมาย ≥ 80%)
- **ผลงาน:** **47.62%** 🔴 **ยังไม่ผ่านเกณฑ์**
- **ปัญหาอุปสรรค:** 
  - การคงอยู่ของแพทย์เวชศาสตร์ครอบครัวในโรงพยาบาลชุมชนยังมีน้อย
  - ปัญหาการโอนย้ายบุคลากรตามนโยบายถ่ายโอน รพ.สต. ไปยัง อปท. ทำให้เกิดสุญญากาศในบางพื้นที่

### 2. ความมั่นคงปลอดภัยไซเบอร์ (Cyber Security HR)
- **ตัวชี้วัด:** โรงพยาบาลมีผู้บริหารความมั่นคงปลอดภัยสารสนเทศระดับสูง (CISO)
- **ผลงาน:** ครบ **100%** 🟢 **ผ่านเกณฑ์**
- **ความสำเร็จ:** ยกระดับการจัดการข้อมูลดิจิทัลเพื่อรองรับ Cloud Health
